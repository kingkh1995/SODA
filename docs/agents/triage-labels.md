# Triage 标签

技能使用五个规范的 triage 角色。本文件将这些角色映射到本仓库 issue tracker 中实际使用的标签字符串。

| 技能中的标签 | 本仓库标签 | 含义 |
| ------------ | ---------- | ---- |
| `needs-triage` | `needs-triage` | 维护者需要评估该 issue |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完备，可供 AFK agent 处理 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不会处理 |

当技能提到某个角色（如"打上 AFK-ready triage 标签"）时，使用表中对应的标签字符串。

如需改用仓库实际使用的其他词汇，编辑右列即可。
